## Instructions

For simple start use `make run`.

This command runs the program with the default map: '**maps/easy/01_linear_path.txt**'

For changing maps or enabling flags, use:

`make run ARGS="--map-path=map --debug"`

Using '=' is allowed only with **--map-path flag**.
